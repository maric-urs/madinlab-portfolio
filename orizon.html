[ Projet ]

Orizon

Plateforme collaborative open source pour centraliser la communication interne et remplacer les serveurs de fichiers par une interface web moderne, rapide et sécurisée.

Logiciel métier · déploiement on-premise

Présentation

Une organisation qui veut un intranet unifié : actualités par service, annuaire des agents, liens vers les applications métier et administration sans multiplier les outils. Tout est développé from scratch, sans modèle tout fait.

Stack technique

  • Nuxt 4 · Vue 3 · Pinia
  • Tailwind · shadcn-nuxt
  • Keycloak (SSO · LDAP/AD)
  • Appwrite · Redis · API Nitro

Fonctionnalités

  • Tableau de bord personnalisé (widgets actualités, annuaire, apps, nouveaux arrivants).
  • Module actualités avec éditeur riche et droits par service.
  • Annuaire agents alimenté par API métier, avec cache Redis pour la résilience.
  • Catalogue d’applications filtré par groupes LDAP.
  • Espace admin (CRUD, médias, santé API).
  • Mode sombre persistant et interface responsive.
