# Portfolio Ursulet Maric (Nuxt 4)

Site vitrine sombre, animations GSAP, tarifs et réalisations.

## Lancer en local

```bash
npm install
npm run dev
```

## Déployer (Vercel)

1. Importer le dossier `ursulet-portfolio` sur [Vercel](https://vercel.com).
2. Framework : Nuxt.
3. Domaine perso recommandé : `ursulet.dev` ou similaire.

## Personnalisation

- Projets & tarifs : `app/data/projects.ts`
- Styles globaux : `app/assets/css/main.css`
